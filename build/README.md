# Making a Windows release build

Make a copy of the `Build-WindowsRelease.ps1.template` file and name it `Build-WindowsRelease.ps1`.

In `Build-WindowsRelease.ps1`, fill the required pieces of information marked by <text in these chevrons>.

Save the file, then open PowerShell, navigate to this directory, and run the script:

```powershell
.\Build-WindowsRelease.ps1
```
